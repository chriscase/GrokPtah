# Pinned Grok CLI 1.0.41 subscription-proxy contract (offline)

**Classification: LOCAL REQUEST-CONTRACT DEFECT REPAIRED — READY FOR REVIEW.** A SHA-verified 1.0.41 binary, run with a synthetic OIDC record behind a native macOS deny-by-default sandbox, sent the intended `grok-build-0.1` turn to `POST /v1/chat/completions`. Its body model and `x-grok-model-override` were both `grok-build-0.1`. The accepted managed relay used that path and body model but omitted the override. The correction adds only the host-sealed model override on the official OIDC CLI-proxy route. This is **offline request-contract parity**, not proof that the missing header caused the historical provider HTTP 403 or that a real account has this model entitlement.
